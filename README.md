# LegalKnowledge
法律律师 RAG：民法典、劳动法、刑法等常见纠纷法条检索问答

项目说明：

models：一些常量，基本上用的都是阿里的模型

cutting.py：主程序，包含初次对整个文件夹的向量化，和向量化后的faiss库（轻量级）加载，运用包括向量检索 + BM25全文关键字的混合检索，索引使用父子索引方式，基本上都是基于langchain框架

new_cutting.py：是增量文件的处理，把文件放在new文件夹即可，这里注意三点，第一，文件新增后要复制到original文件夹，因为混合检索，BM25需要用到，第二，避免重复向量化，因为演示作者没有做向量数据的记录和验重，第三，这里仅处理了docx，如果其他文件如PDF需要使用如MinerU组件（推荐），如果是doc文件，要引入对应的组件，并对程序做小的修改
